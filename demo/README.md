# CrewForge public product preview

This directory contains the lightweight interactive product preview deployed at the public demo URL. It lets visitors explore team creation, skill discovery, open-seat availability and the member journey. Preview changes are stored in the visitor’s browser.

The full application implementation, API, MongoDB persistence, authentication, transactional membership logic, automated tests, architecture notes and performance evidence live in the repository root. The preview is intentionally separate from the full-stack service.
