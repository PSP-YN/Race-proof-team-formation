# CrewForge — static demonstration

This folder contains the no-backend, no-API interactive demo intended for hackathon judging.

- Pure static HTML, CSS and browser JavaScript.
- No API calls, backend, account creation, database, analytics, or external asset/font requests.
- Team create/join/leave, skill search and match suggestions are simulated in the browser.
- Demo state is stored only in the visitor's local browser storage.
- Reset Demo clears the browser's CrewForge demo state and restores fixture teams.

The full Next.js + MongoDB implementation remains in the repository root. This static demo is not a production account/team service and must not be described as such.
